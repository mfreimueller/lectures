== Installing JDK

Download from https://adoptium.net[Adoptium] or use SDKMAN:

[source,bash]
----
# Using SDKMAN
sdk install java 25.0.3-tem
java --version
javac --version
----

== Maven Setup

Install via IntelliJ or use SDKMAN:

[source,bash]
----
# Using SDKMAN
sdk install maven
mvn --version
----
