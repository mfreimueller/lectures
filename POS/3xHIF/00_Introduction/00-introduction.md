## Installing JDK

Download from [Adoptium](https://adoptium.net) or use SDKMAN:

```bash
# Using SDKMAN
sdk install java 25.0.3-tem
java --version
javac --version
```

---

## Maven Setup

Install via IntelliJ or use SDKMAN:

```bash
# Using SDKMAN
sdk install maven
mvn --version
```
