== The POS Year in Review

* Java: from modern language features to enterprise patterns
* 33 weeks of programming, exercises, and projects
* From Records to REST APIs
* From unit testing to full-stack project work

== Topic Block 1: Modern Java

* Records, sealed classes, pattern matching
* Optional, switch expressions, text blocks
* Unnamed variables, utility APIs
* var: local variable type inference

== Topic Block 2: Testing & Design

* JUnit Jupiter, AssertJ, parameterized tests
* TDD: Red-Green-Refactor
* SOLID principles with practical exercises
* FIRST principles for good tests

== Topic Block 3: Streams & Functional

* filter, map, flatMap, reduce
* Collectors: groupingBy, partitioningBy
* Exercise: CLI Todo App
* Exercise: Markdown to HTML Converter

== Topic Block 4: Reflection & Databases

* Reflection API: Class, Methods, Fields
* Annotations: definition, retention, processing
* JDBC: Connection, Statement, ResultSet
* JPA: Entities, JPQL, relationships, inheritance

== Topic Block 5: REST & Architecture

* HTTP, REST principles, Java HttpClient
* Servlets & Front Controller pattern
* DTOs, validation, error handling
* Layered architecture: Controller, Service, Repository

== Topic Block 6: POS-WMC Project

* 6 weeks of project work
* Custom domain and database model
* Authentication, JPA entities, REST API
* Testing, documentation, submission

== Key Skills Acquired

* Modern Java programming (Java 17-21)
* Test-driven development
* Object-oriented design principles
* Database access with JDBC and JPA
* REST API development

== Outlook: 4th Grade - Spring Boot

* Spring Boot: the industry standard for Java web apps
* Dependency injection, auto-configuration
* Spring Data JPA, Spring Security
* REST with Spring MVC
* Testing with Spring Boot Test
